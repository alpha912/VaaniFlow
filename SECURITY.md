# Security Policy

If you discover a security vulnerability in VaaniFlow, please report it privately
via GitHub Security Advisories.

## Reporting

- Open the report page here:
  https://github.com/alpha912/VaaniFlow/security/advisories/new

Please include:

- Affected version(s) and platform (Windows/macOS/Linux)
- Clear reproduction steps
- Impact and severity assessment
- Logs or stack traces (without secrets)

Please do not disclose the issue publicly until we confirm and release a fix.

## Scope

- This policy applies to the public repository:
  - https://github.com/alpha912/VaaniFlow
- Use the latest version whenever possible for all security-sensitive evaluation.

## Versions covered

- We support the latest `main` branch and tagged releases.
- For older versions, please include exact version information in your report.
